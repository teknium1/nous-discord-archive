    **Anvil is public** — a mobile client for Forgejo, Android and iOS from one codebase.
    https://github.com/THEROCKSSS/anvil
    
    Browse your instance from your phone: explore repos, orgs and users, read code,
    track milestones and issues. MIT licensed, unofficial, not affiliated with Forgejo.
    
    **What works**
    - Explore repos / orgs / users, with search and sort
    - Repo overview with languages, branches, releases
    - File browser — tap into folders, read files with line numbers
    - Cross-repo milestone board with progress and due dates
    - Cross-repo issues and PRs, filter by repo or text
    - Issue detail with comments
    - Diagnostics screen that tells you exactly which token scope is missing
    
    **Running it**
    No Mac and no Apple Developer account needed. Install Expo Go from the App Store,
    point it at the dev server, sign in with a read-only Forgejo token.
    `docker compose up -d --build` if you want it always on.
    
    **Known limits**
    - Read-only for now, no commenting or merging yet
    - Issue bodies render as plain text, no Markdown yet
    - Pinned to Expo SDK 54, because the App Store build of Expo Go only runs 54
    - No offline cache
    
    Issues and PRs welcome.
