    Hey Hermes folks 👋 Built Belay — an open-source guardrail that plugs into Hermes' pre_tool_call hooks and checks every tool call before it runs: 🛑 blocks the dangerous ones (secret exfil, rm -rf, reverse shells, prompt injection), 🤔 asks you (one-tap Allow/Deny) on the gray areas. Deterministic (no LLM judging the LLM), sub-100ms, local-first, AGPL. So you can run Hermes unattended with a seatbelt.
    → https://github.com/SECBLOK/belay
    Anyone running Hermes unattended — what tool calls make you nervous? 🙏
