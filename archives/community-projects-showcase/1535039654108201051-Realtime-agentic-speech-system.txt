    I recently built a realtime speech system which utilizes chatgpt-realtime-2.1 (a state-fo-the-art realtime speech model by openai), and sits as a voice layer on top of hermes.
    
    Simple commands for music, timers and such run in real-time with no interruption. Complex requests such as coding or research run in the background on hermes (via the Kanban board). 
    
    Some key features:
    - Lightweight wakeword listener model and process (~250kb in RAM, little to no impact on device performance)
    - Tray icon process, to easily control the listener or trigger manually
    - Fast tools are fully extensible - simply request to build a new tool, and a Kanban request for your hermes agent will be generated, to add it to the speech system for you.
    - True, smooth, realtime voice-to-voice interaction.
    - Error logging, to easily diagnose and fix problems as they occur.
    
    Try it out!
