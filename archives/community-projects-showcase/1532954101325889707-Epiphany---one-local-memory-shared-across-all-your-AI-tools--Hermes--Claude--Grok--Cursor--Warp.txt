    Hey all, I built Epiphany and wanted to share it here since this channel clearly loves agent memory.
    
    Most memory tools live inside one agent. Epiphany is one memory that ALL your tools share: Hermes, Claude, Grok, Gemini, Cursor, and Warp all read and write the same brain through MCP. Tell one, the others already know.
    
    Local-first: it's a SQLite file on your own machine, embeddings run on-device, nothing leaves your box. No account, no cloud.
    Reasoning graph, not bullet points: thoughts carry typed connections (because, builds_on, contradicts), so when you ask "why" it walks the chain back to the decision, not just a matching fact.
    Hermes support built in: "epiphany connect hermes" wires it into ~/.hermes via hermes mcp add.
    Never lose a session: a background watcher files your session logs into memory automatically, even ones that crashed.
    MIT, just went live on npm and the MCP Registry.
    Install: npm i -g epiphany-mcp
    Code: github.com/GATSV-tech/epiphany
    
    Would love feedback, especially from folks who've built the other memory tools in here. Happy to answer anything.
