    I created a port for the desktop app that runs in a browser. Docker, it points at any Hermes dashboard URL via HERMES_TARGET inside the .env. I will be improving the UI to make it more usable in a phone's webapp as well as multi-gateway support soon.
    I will keep up with the official Hermes updates which keeps the renderer actually follows your Hermes backend updates.
    Repo: https://github.com/walodayeet/Hermes-Desktop-Web-Port (unofficial)
    If you have any problems with the webUI, tell me here or add into issues.
