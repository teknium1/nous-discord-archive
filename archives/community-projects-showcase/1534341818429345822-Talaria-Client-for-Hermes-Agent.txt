    # Talaria 🪽, a native iOS client for Hermes Agent
    
    Was having behavior issues with WebUI for Hermex that I wasn't having on the Hermes Desktop app, so I worked on a native iOS app with an intuitive UI similar to iMessage. It speaks to hermes-agent's own gateway, so if you're running hermes serve you're most of the way there already. I have found it to be incredibly reliable.
    
    ## Chat
    
    Streaming replies with reasoning as it thinks, and tool calls with their output
    Subagent delegation — what got delegated, how far along, what failed
    Interrupt, steer mid-run, redirect
    Branch a conversation, undo a turn, compress context
    Slash commands, image attachments, voice input
    Permission prompts
    Approval, clarify, secret and sudo requests, timeouts included. You can run an agent that asks before it acts and answer it from your phone.
    
    ## The agent's own state
    
    Skills — browse and toggle
    Tools and toolsets
    MCP servers
    Scheduled tasks
    Memory / learning graph
    Workspace file browser
    Token spend and usage analytics
    Config, driven by your server's own schema
    Profiles, with per-profile session lists
    Provider OAuth
    Sessions
    Search across all of them, pin, archive, resume, rename. Transcripts cache on device, so they open instantly and read fine with no signal.
    
    ## Voice
    
    Full conversation mode, speech in and out, either on-device or through your server. Keeps going with the screen off.
    
    ## Connecting
    
    Straight to a gateway on your network
    Over SSH it generates a key in the Secure Enclave, pins the host key, starts hermes serve on the far side and tunnels to it. Nothing exposed, no ports forwarded, no VPN
    Hermes Cloud via Nous Portal sign-in
    Elsewhere in iOS
    Siri and Shortcuts, Spotlight search over your conversations, a notification when a turn finishes, keyboard shortcuts, and a real iPad layout with sidebar and split view (less tested than iPhone).
    
    No gateway to hand? Sample-data mode covers every screen above, so you can look through the whole app before pointing it at anything real.
    
    It's 0.1 so expect rough edges. TestFlight link https://testflight.apple.com/join/UtMgYYNA. Feel free to DM with any problems. I couldn't test a lot of providers and Hermes Portal logins.
