    🚨 Hermes Signals is live.
    
    A small local-first quality layer for Hermes Agent that catches:
    
    ❌ false success
    🔁 retry loops
    ✏️ unverified changes
    🔐 secret risk
    
    No GPU. No API key. No hosted service. No outbound telemetry.
    
    Install:
    
    hermes plugins install DECRUX9812/hermes-signals --enable
    
    Then run:
    
    hermes signals demo
    
    Please try it on some messy real-world traces and tell me where it gets things wrong.
    
    ✅ correct
    ❌ false positive
