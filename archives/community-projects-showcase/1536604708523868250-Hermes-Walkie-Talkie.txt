    Claude Code recently shipped session-to-session messaging—and I wanted the same capability for Hermes.
    
    The idea is simple: stop acting as the human message bus between parallel AI sessions.
    
    So I built Hermes Walkie Talkie:
    
    - Send a summary or question directly to another live Hermes session—not its full history or files.
    - Receive replies back in the original session.
    - Let an agent notify another session when its changes affect that agent’s work.
    - Queue messages safely when the receiving agent is busy.
    - Keep communication owner-local, with exact-session targeting and delivery receipts.
    
    Think backend, frontend, security and QA agents working in parallel—sharing contract changes, findings and blockers without you repeating everything across four terminals.
    
    Current state:
    
    - V1 standalone repo: https://github.com/Sahil-SS9/hermes-walkie-talkie
    - Open Hermes core PR: https://github.com/NousResearch/hermes-agent/pull/83661
    - V1.1 next: groups, broadcasts, structured requests, progress tracking and full multi-agent workflows.
