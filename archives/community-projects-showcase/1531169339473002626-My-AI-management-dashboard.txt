    Used minimaxm3 as workers qwen3.8max as orchestrator.
    The dashboard now gives me a live overview of:
    
    • SuperGrok
    • Codex
    • Kimi Code
    • Hypercredits
    • MiniMax
    • Alibaba Token Plan
    • Quota percentages and reset timers
    • Night-discount status
    • Hermes token usage and request activity
    • 7-day usage insights

    Finally i dont need to have multiple tabs open on my browser to check the quota of all...
