    I developed a Hermes Desktop Plugin that lets you select any text inside Hermes Desktop and a popup offers you two actions: *respond* quotes the selection into the chat-field as a reply similar to how you can quote specific text parts in Claude, ChatGPT. *Define* lets you stream an AI-Generated definition into a panel (Providers are Pre-imported from the gateway, you can add Custom Providers though). The definitions contain web search results (toggleable), inline-cited sources and a thumbnail. The Response is stateless by design, meaning that there is no Agent Loop, no memory, the only bottleneck is AI-Inference from your Provider (and Web Search, if enabled).
    You can also customize the template prompt that the AI gets. Its MIT-Licensed, so feel free to fork and add suggestions (more details in the GitHub Repo)
    https://github.com/BrokeSkill/Hermes-Insight,  if you do find any issues, you can write them in this thread, create an Issue on GitHub or DM me.
