    **Hermes Client Agent v1.1.0-beta — Your machine, controlled by Hermes**
    
    After several weeks of intense refactoring, here's the current state of **hermes-client-agent**, a lightweight Python agent (~100 MB RAM) that lets Hermes control remote machines — Windows, Linux, and soon macOS.
    
    **What's available today:**
    - **25 tools** in the native Hermes plugin: shell, files, mouse, keyboard, windows, screenshot, processes, and **code delegation via ACP** (OpenCode)
    - **Web dashboard** with structured audit logging
    - **186 tests** pytest + CI/CD via GitHub Actions
    - **Standalone .exe** (23.5 MiB) for Windows + install scripts
    - **Tailscale** for remote access with zero open ports
    
    **The ACP feature (brand new):**
    Hermes can now delegate coding tasks to OpenCode on a remote machine — the plugin handles spawn, session reuse, provider detection, and async polling automatically. Zero config for the user. Fully transparent.
    
    **Architecture:**
    ```
    Hermes (NAS Docker) → windows_control plugin → FastAPI Agent (remote machine) → OpenCode
    ```
