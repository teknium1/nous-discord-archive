    LLM arithmetic is unreliable, especially past ~150k context. This skill fixes it: if there are 3+ numbers, write code. Every time.
    
    What it does:
    • Routes all math through execute_code or Python scripts — never in-head
    • Enforces self-check assertions against source data
    • Covers SDE, margins, growth rates, annualizations, rollups, weighted averages
    • Handles Excel/CSV/API inputs with pitfall guards (data_only=True, whitespace stripping, etc.)
    
    Install:
    
    hermes skills tap add tommulkins/hermes-skill-math-via-code
    hermes skills install tommulkins/hermes-skill-math-via-code/math-via-code
    
    Also works with Claude Code, Cursor, Codex, and 70+ agents via npx skills add tommulkins/hermes-skill-math-via-code.
