    Hermes Agent has a built-in memory tool limited to ~2.2KB. When it fills up, older entries get compressed or lost. Mnemosyne removes that limit by storing memories as markdown files on your own filesystem — no third-party services, no API keys, no cloud dependencies.

[2026-08-11T00:22:25.040000+00:00] badstyles (id=1536530191650914305)
    Response to community feedback on Mnemosyne:
    
    Thank you for the feedback. To clarify a few points:
    
    Regarding the name "Mnemosyne" — Yes, we're aware Hermes has a built-in memory tool also called Mnemosyne. Our plugin is named after the Greek goddess of memory, not as a competing product. The built-in Mnemosyne (2.2KB limited) and our vault-backed Mnemosyne (unlimited storage) are complementary, not competing — our plugin mirrors the built-in memory writes into unlimited markdown files and injects relevant context via prefetch before each turn. They work together.
    
    Regarding SkyLinx's Obsidian importer — Interesting approach. Our implementation works in the opposite direction: it writes through to an Obsidian-compatible vault automatically and searches with ripgrep. No periodic imports, no watchers, no watchers — it's automatic write-through.
    
    Our plugin is open source on GitHub. If anyone wants to use it or adapt it, they're welcome to.
