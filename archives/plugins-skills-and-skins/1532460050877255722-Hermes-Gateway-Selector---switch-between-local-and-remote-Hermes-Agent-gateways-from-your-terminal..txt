    Running bare hermes pops an interactive picker. All other commands pass through unchanged. Supports password-authenticated gateways (gated mode).
    
    ─ bash
    
    # Install via skills.sh (works across agents)
    `npx skills add tommulkins/hermes-gateway-selector`
    
    # Or via Hermes tap
    ```sh
    hermes skills tap add tommulkins/hermes-gateway-selector
    hermes skills install tommulkins/hermes-gateway-selector/hermes-gateway-selector
    ```
    
    Use case: run Hermes locally, pick which gateway on a remote machine to connect to. Good for home server / work laptop / VPS setups.
