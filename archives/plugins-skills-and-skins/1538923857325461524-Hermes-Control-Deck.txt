    I finally made a clean version of Hermes Control - built for other people to actually use.
    
    The original version was designed around my own setup: Codex, Hermes, remote access, custom bridges, and a lot of things that only made sense on my machines.
    
    This version changes that.
    
    Hermes Control Clean is a simplified, portable control deck for managing Hermes + Codex remotely from your phone.
    
    From one interface you can:
    
    → Send prompts and start new tasks
    → Monitor active sessions and runtime status
    → View logs
    → Approve / deny actions
    → Stop running tasks instantly
    → Switch sessions
    → Control reasoning level
    → Trigger Hermes remotely
    → Manage both Codex CLI and Hermes from the same mobile dashboard
    
    The goal is simple:
    
    Start something on your computer. Walk away. Keep control from your phone.
    
    No Termius. No constantly opening a terminal. No sitting in front of the PC waiting for an agent to finish.
    
    I originally built Hermes Control because I wanted this workflow for myself.
    
    Now I’m cleaning up the architecture, setup and configuration so other people can run it too.
    
    Still experimental. Still evolving. But now it’s becoming something you can actually install and make your own.
    
    Hermes Control - your agents don’t need you at the desk.
