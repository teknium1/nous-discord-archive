    Hey everyone,  I’ve been building hermes x402, a standalone community plugin that adds Circle x402 payment capabilities to Hermes Agent.
    
    It integrates directly through the `hermes_agent.plugins` entry point and currently provides 14 tools plus a `/x402` command for status, wallet readiness, supported networks, service inspection, configuration, Gateway balances, deposits, and paid-resource access.
    
    Current capabilities include:
    
    • discovering and inspecting x402-enabled services
    • checking payment requirements without paying
    • paying for protected HTTP resources with USDC
    • Circle Agent Wallet CLI and Developer-Controlled Wallet support
    • Circle Gateway balance and deposit preview/execute flows
    • seller middleware for protecting aiohttp endpoints
    • buyer, seller, and dual-role agent workflows
