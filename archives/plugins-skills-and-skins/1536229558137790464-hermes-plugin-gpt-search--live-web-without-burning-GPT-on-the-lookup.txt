    **hermes-plugin-gpt-search** is out
    
    Live web search for Hermes Agent, powered by OpenAI Codex's standalone search path. Your active model stays the reasoner. The lookup itself isn't a GPT completion turn.
    
    **Install**
    ```
    hermes plugins install Adolanium/hermes-plugin-gpt-search --enable
    ```
    
    **You need**
    - Hermes Agent
    - `codex login` *or* `CODEX_ACCESS_TOKEN` in your Hermes env
    
    Then:
    ```
    hermes gpt-search doctor
    ```
    
    **What you get**
    - `gpt_search` — one-shot live search
    - `gpt_web` — multi-step research (search → open page → find → click)
    - `/gpt-search <query>` — skill slash, agent answers in a normal chat bubble
    - `hermes gpt-search search "…"` — terminal, no agent required
    
    **Why bother**
    Reuse the Codex/ChatGPT session you already have. Sticky research sessions so `ref_id`s work across turns. Results cleaned for the context window. Errors that tell the model what to do next instead of dying mid-thought.
    
    Repo: https://github.com/Adolanium/hermes-plugin-gpt-search
    
    Questions / bugs welcome. If it breaks, `hermes gpt-search doctor` first.
