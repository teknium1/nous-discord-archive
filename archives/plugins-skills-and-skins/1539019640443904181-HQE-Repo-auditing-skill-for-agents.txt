    This agent skill transforms an AI coding agent from a “looks-good-to-me” reviewer into a protocol-driven senior code auditor. Based on HQE Protocol v5.0.0, it requires the agent to support its findings with concrete repository evidence instead of speculating or inventing vulnerabilities.
    
    After installation in an AI coding environment, you can run commands such as `/HQE audit`, `/HQE security`, `/HQE pr-review`, `/HQE remediate`, and `/HQE verify`, and many more. The skill inventories the repository, identifies its ecosystem and testing tools, evaluates architecture, security, reliability, performance, and test coverage, validates its findings, assigns severity and confidence levels, and produces structured audit artifacts.
