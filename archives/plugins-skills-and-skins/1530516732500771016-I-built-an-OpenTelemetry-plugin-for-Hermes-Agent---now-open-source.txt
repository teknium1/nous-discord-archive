    I built an OpenTelemetry plugin for Hermes Agent — now open source
    
    hermes-otel-plugin gives every Hermes turn a proper end-to-end trace:
    
    one invoke_agent span per turn
    one chat span per LLM call
    one execute_tool span per tool call
    real durations, token usage, finish reasons, time-to-first-token, and cost
    OpenTelemetry GenAI semantic conventions, compatible with Jaeger, Grafana Tempo, Honeycomb, and any OTLP backend
    Prompt, response, and tool content are privacy-gated and only exported when explicitly enabled. The plugin is fail-open, requires no Hermes core changes, and includes 44 unit tests using in-memory exporters.
    
    Install it with:
    
    hermes plugins install Mandark-droid/hermes-otel-plugin
    hermes plugins enable otel
    Repo (MIT, v1.1.1): https://github.com/Mandark-droid/hermes-otel-plugin
    
    The attached screenshot is a live Hermes turn in stock Jaeger: an LLM call, two parallel file reads, and the final answer, all with their real measured durations. Feedback and ideas for useful agent telemetry are very welcome.
