    A small ⚕ in the menu bar: gray when idle, green when Hermes is working, orange when memory pressure is critical. A pressure dot (🟡 warning / 🔴 critical) appears whenever memory pressure isn't green. Click for RAM %, swap, CPU %, and the active session name. Native Swift NSStatusItem (not rumps — those fail to compile on macOS 26); a Python poller reads memory_pressure + live agent-process CPU. Install: hermes skills install https://raw.githubusercontent.com/ncline-ui/hermes-statusbar/main/SKILL.md Source: ncline-ui/hermes-statusbar · GitHub (MIT)
