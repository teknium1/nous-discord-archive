    ForgeCat does two things.
    It's a hub where you browse and share agent profiles,
    and it's a CLI that manages them on your machine (install, update, uninstall, version pinning).
    
    Hermes is one of the install targets. forgecat install <profile> -p hermes finds your profile home, drops the skills into <home>/skills/ as-is, and merges the persona and instruction parts into SOUL.md.
    Your config.yaml and MCP setup are left alone.
    
    Profiles are cross-platform, so a setup someone built for Claude Code or Codex or Cursor carries over to Hermes without porting anything.
    Same in reverse when you publish your own with forgecat init then forgecat push.
    
    npm i -g forgecat
    forgecat search
    forgecat install @forgecat/<profile> -p hermes
