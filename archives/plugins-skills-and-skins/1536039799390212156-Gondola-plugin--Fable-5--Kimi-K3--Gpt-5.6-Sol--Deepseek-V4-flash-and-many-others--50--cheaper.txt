    Shipped a model-provider plugin for **Gondola (gondola-ai.com)**, a USDC-settled marketplace
    for Venice AI inference. (Not the travel-booking Gondola with the MCP entry, different company.)
    
    Each request routes to the cheapest supplier on the Venice catalog, so prices sit below Venice
    list. Pay per request from a USDC balance on Base. No subscription, no Venice account. Prompts
    and completions are never persisted.
    
    Install:
    
    ```
    mkdir -p "$HOME/.hermes/plugins/model-providers"
    git clone https://github.com/Gondola-Market/hermes-gondola-provider \
      "$HOME/.hermes/plugins/model-providers/gondola-provider"
    export GONDOLA_API_KEY=gnd_...
    ```
    
    Gondola then shows up in `hermes model` with a live catalog (filtered to chat-capable models;
    the raw catalog also has image/video) and a `hermes doctor` connectivity row. 100+ text models: GPT-5.6, Claude Opus 5 and Fable 5,
    Gemini 3.6 Flash, Grok 4.20, Kimi K3, DeepSeek V4, hermes-3-405b, the venice-uncensored line.
    Live price comparison vs the official APIs: gondola-ai.com/models.
    
    The API also takes accountless per-request x402 payments (402 challenge, USDC on Base) for
    agents that speak the protocol; the plugin itself uses plain API-key auth.
    
    Keys: gondola-ai.com/wallet (format `gnd_...`). Setup guide: gondola-ai.com/guides/hermes-agent.
    
    https://github.com/Gondola-Market/hermes-gondola-provider
