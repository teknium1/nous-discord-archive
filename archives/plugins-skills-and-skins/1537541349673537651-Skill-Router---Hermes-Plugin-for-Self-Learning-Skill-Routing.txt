    The Skill Router makes skill suggestions task-based and self-learning: it injects the relevant skills for each task, learns from actual usage (word-tool co-occurrence with lift weighting), and grows automatically. New skills in the system are recognized without any configuration.
    
    Features:
    
    Task-based skill routing (injection before the LLM call)
    Self-learning lexicon: words associate with tools/skills via co-occurrence and lift
    Automatic genericity detection (DF-based): noise words are cleaned up automatically
    Live dashboard: cluster view of all skills with causal words, last injection, 5-second auto-refresh
    Privacy-first: learned data (personal words) stays local, never in the repo
    CI: tests + lint on GitHub Actions
    Installation: 
    
    hermes plugins install xXLODXx/hermes-skill-router
