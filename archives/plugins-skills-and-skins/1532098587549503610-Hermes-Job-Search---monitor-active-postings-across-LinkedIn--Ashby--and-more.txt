    Hey guys,
    
    I wanted to share an open source plugin that turns Hermes into a job search assistant.
    
    **How it works:**
    
    Install the plugin, then tell Hermes what you’re looking for:
    
    *Example:*
    
    ```
    Set up my job search. I’m looking for a senior software engineering role at a technically ambitious, remote-friendly company building AI-native tools or developer infrastructure. I value autonomy, meaningful ownership, and open-source work.
    ```
    
    Hermes will ask follow-up questions if needed and document your preferences locally.
    
    It will then pull live job postings from LinkedIn and applicant-tracking systems like Ashby, Greenhouse, and Lever.
    
    Additionally, Hermes will:
    - Filter out jobs that clearly violate your preferences and deal-breakers
    - Group the remaining jobs as strong, moderate, or weak matches
    - Explain why each job matched
    - Flag important details that weren’t answered in the posting
    
    Optionally, Hermes can also run the search on a schedule (e.g., every morning). 
    
    **Getting started:**
    
    Copy and paste the following into a new Hermes session:
    
    ```
    Retrieve and follow the installation instructions at:
    https://raw.githubusercontent.com/agent-data/job-search/main/INSTALL_FOR_HERMES.md
    ```
    
    The plugin uses agent-data to pull live job postings, so you’ll need an API key (no credit card required).
    
    **Repo**: https://github.com/agent-data/job-search (MIT license)
    
    If anyone’s currently on the job hunt, I’d love to hear how I can make this plugin more useful!
