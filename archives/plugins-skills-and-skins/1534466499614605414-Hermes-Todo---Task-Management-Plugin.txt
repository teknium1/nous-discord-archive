    A shared task board for Hermes Desktop and Hermes agents.
    This is purposely not a kanban, but instead a "Todoist" style task management plugin for getting work done with your agent!
    
    **What it includes**
    - **Now**, **Today** and **Later** planning
    - **Open**, **Waiting**, **Blocked** and **Done** statuses
    - Due dates and timed deadlines
    - Priorities, projects and estimates
    - Recurrence notes
    - One shared board across Desktop, CLI, REST API and agents
    - **Work with Hermes** to open a dedicated session for a task
    - Profile-scoped SQLite storage, so Desktop and agent changes stay in sync
    
    **Repository:**
    https://github.com/DanBennettUK/hermes-todo
    
    Feedback, bug reports and PRs are very very welcome!
