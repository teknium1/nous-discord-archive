    Nice little Hermes plugin for OpenAlex.
    
    Look up works, authors, sources, and institutions. `get` is metadata (title, year, venue, authors), not the PDF. `fulltext` without `--confirm` only checks whether OpenAlex has the text. `--confirm` downloads it for $0.01.
    
    No key needed. Anonymous is $0.10/day. A free key is $1/day. ID lookups and name resolve are $0 and still work when the daily budget is gone.
    
    ```
    hermes plugins install Adolanium/hermes-plugin-openalex --enable
    ```
