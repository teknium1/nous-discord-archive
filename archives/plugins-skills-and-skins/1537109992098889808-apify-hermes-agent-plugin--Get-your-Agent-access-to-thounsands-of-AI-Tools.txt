    Hey folks! 👋
    
    We just shipped **apify-hermes-agent-plugin** to PyPI 🐍🚀
    
    It plugs Apify into your Hermes Agent and gives it access to the entire Apify Store — thousands of ready-made Actors for scraping, automation, and data extraction. Your agent can discover, run, and collect results from any of them.
    
    **What you get:**
    - `apify_discover` — search the Apify Store or pull an Actor's input schema + README
    - `apify_start` — batch Actor starts (up to 10 per call, so your agent isn't stuck waiting on one scrape at a time)
    - `apify_collect` — poll run status and pull back the finished dataset
    - `hermes apify-setup` — one CLI command to save your API token and flip the toolset on
    
    Give it a spin and let us know what you build 💪
    
    PyPI: https://pypi.org/project/apify-hermes-agent-plugin/
    GitHub: https://github.com/apify/apify-hermes-agent-plugin
