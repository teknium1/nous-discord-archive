    Hermes agents shouldn’t be islands. Herald gives them four explicit ways to worktogether:
    
    • Persistent cross-profile chat — talk directly with separately configured Hermesprofiles
    • Async dispatch + callbacks — hand work to specialist agents and collect resultslater
    • Model-selectable subagents — choose a model per task without changing the parentruntime
    • Pure inference — one-shot text or validated JSON via llm_call, with no tools oragent harness
    
    It includes 11 tools, a durable SQLite audit ledger, fail-closed route verification,and zero Hermes core patches.
    
    Install:
    
    hermes plugins install bennybuoy/hermes-herald --enable
    
    GitHub and documentation:
    Hermes Herald
    
    Feedback, experiments, bug reports, and sharp-edge discoveries are very welcome.
