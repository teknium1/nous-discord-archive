    We opened a PR adding emem to the optional-mcps catalog: https://github.com/NousResearch/hermes-agent/pull/79583
    
    emem is a remote MCP server (no auth, nothing to install) that gives agents signed, citeable facts about real-world places powered by real satellites plus agents' own data. Every fact carries an ed25519 signature and a resolvable emem:fact: token; receipts verify offline against a transparency log. Useful anywhere an agent states something about the physical world and you want that claim checkable.
    
    Try it without installing anything: point Hermes at https://emem.dev/mcp , https://github.com/mcp/Vortx-AI/emem and ask it to locate a place and recall the signed a fact like weather, elevation there. Feedback welcome, especially on the default tool selection.
